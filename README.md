## 🚀 About
An EEG-based BCI system that captures brain signals, processes neural activity, and converts patterns into computer commands using signal processing and machine learning.

## ⚙️ Workflow
📡 EEG Acquisition → 🧹 Preprocessing → 🤖 Classification → 🎮 Output

## 🛠️ Tech Stack
- 🐍 Python
- 📊 NumPy, SciPy
- 🧠 MNE-Python
- 🤖 Scikit-learn

## ✨ Features
- Real-time EEG analysis *(if implemented)*
- Brain-signal classification
- Visualized prediction results

## ▶️ Run
```bash
pip install -r requirements.txt
python src/train.py
```

Real-time control, improved accuracy, and smart assistive applications.
